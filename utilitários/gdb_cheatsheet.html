GDB Cheat Sheet

Guia de Referência Rápida para Depuração Visual e Intuitiva

🚀 Execução (Running)

gdb <programa> [core dump]
Inicia o GDB (com core dump opcional).
gdb --args <programa> <args...>
Inicia o GDB e passa argumentos diretamente da linha de comando.
gdb --pid <pid>
Inicia o GDB e se anexa a um processo em execução.
set args <args...>
Define os argumentos a serem passados ao programa que será depurado internamente.
run
Executa o programa a ser depurado do início.
kill
Encerra abruptamente o programa em execução no depurador.

🛑 Pontos de Parada (Breakpoints)

break <where>
Define um novo ponto de parada no local especificado.
delete <breakpoint#>
Remove permanentemente o ponto de parada especificado pelo número.
clear
Deleta todos os pontos de parada configurados no programa.
enable <breakpoint#>
Ativa um ponto de parada que havia sido previamente desativado.
disable <breakpoint#>
Desativa temporariamente um ponto de parada sem removê-lo.

📍 Especificando Locais (<where>)

nome_da_funcao
Interrompe ou observa a execução logo na entrada da função nomeada.
numero_da_linha
Interrompe ou observa o número da linha correspondente no arquivo fonte atual.
arquivo:numero_da_linha
Interrompe ou observa a linha específica dentro do arquivo fonte nomeado.

⚖️ Condições (Conditions)

break/watch <where> if <condicao>
Gera uma interrupção no local apenas se a condição associada for atendida.
As condições podem ser quase qualquer expressão em C que resulte em verdadeiro (true) ou falso (false).
condition <breakpoint#> <condicao>
Define ou altera dinamicamente a condição de um break- ou watchpoint já existente.

👁️ Observadores (Watchpoints)

watch <where>
Define um novo ponto de observação para monitorar alterações em variáveis ou endereços.
delete/enable/disable <watchpoint#>
Gerenciamento idêntico aos comandos aplicados a breakpoints.

🥞 Examinando a Pilha (The Stack)

backtrace / where
Exibe a pilha de chamadas de funções ativas até o momento atual.
backtrace full / where full
Mostra a pilha de chamadas completa, imprimindo também os valores das variáveis locais em cada frame.
frame <frame#>
Seleciona o frame específico da pilha de execução para inspeção detalhada.

🚶 Navegação (Stepping)

step
Avança para a próxima linha de código fonte, entrando no escopo de funções internas.
next
Avança para a próxima instrução/linha, mas pula por cima de chamadas de funções.
finish
Continua a execução ininterrupta até que a função corrente retorne ao seu chamador.
continue
Retoma a execução normal do programa até encontrar o próximo ponto de interrupção.

💾 Variáveis e Memória

print/formato <what>
Exibe o conteúdo atual de uma variável, registrador ou endereço de memória.
display/formato <what>
Semelhante ao print, mas exibe automaticamente as informações atualizadas após cada passo de instrução.
undisplay <display#>
Remove o monitoramento automático do display correspondente ao número informado.
enable/disable display <display#>
Ativa ou desativa temporariamente a exibição automática do monitoramento.
x/nfu <address>
Inspeciona diretamente a memória bruta no endereço informado.
n: Quantidade de unidades a exibir (padrão 1).
f: Caractere de formatação (conforme tabela de Formatos).
u: Tamanho da unidade: b (Byte), h (Half-word/2 bytes), w (Word/4 bytes), g (Giant word/8 bytes).

📊 Formatos de Exibição (Format)

Sintaxe Descrição do Formato
aPonteiro / Endereço (Pointer)
cLê como inteiro e imprime como caractere (char)
dInteiro decimal com sinal
fNúmero de ponto flutuante (float/double)
oInteiro impresso em base octal
sTenta tratar e exibir o conteúdo como String em C
tInteiro impresso em formato binário (t = "two")
uInteiro decimal sem sinal (unsigned)
xInteiro impresso em formato hexadecimal

🔍 Alvos de Inspeção (<what>)

expressao
Qualquer expressão C válida, incluindo chamadas de função (deve-se usar um cast explícito para indicar o tipo de retorno ao GDB).
nome_arquivo::nome_variavel
Acessa o conteúdo de variáveis estáticas ou globais restritas ao arquivo fonte nomeado.
funcao:nome_variavel
Acessa variáveis locais de uma função específica (caso ainda estejam na pilha).
{tipo}endereco
Interpreta o conteúdo contido em um endereço de memória bruto sob a ótica do tipo C informado.
$registrador
Conteúdo de um registrador da CPU. Exemplos comuns: $esp (stack pointer), $ebp (frame pointer), $eip (instruction pointer).

🛠️ Manipulando o Programa

set var <nome_variavel>=<valor>
Altera forçadamente o valor de uma variável em tempo de execução.
return <expressao>
Interrompe a função corrente e força um retorno imediato com o valor da expressão fornecida.

🧵 Threads

thread <thread#>
Seleciona a thread específica pelo seu identificador para execução de comandos subsequentes.

📂 Gerenciamento de Fontes

directory <diretorio>
Adiciona um caminho ao índice de busca onde o GDB procura pelos arquivos de código fonte.
list
Exibe as linhas do código fonte ao redor da instrução atual.
Variações aceitas:
list <arquivo>:<funcao>
list <arquivo>:<linha>
list <inicio>, <fim> (se fim for omitido, inicia a listagem a partir de início).
set listsize <quantidade>
Define o número de linhas de código exibidas por padrão a cada comando list.

⚡ Sinais (Signals)

handle <sinal> <opcoes>
Configura o comportamento do GDB ao interceptar sinais do sistema operacional.
Opções disponíveis:
• (no)print: (Não) exibe mensagens de aviso quando o sinal disparar.
• (no)stop: (Não) pausa a execução do programa na ocorrência do sinal.
• (no)pass: (Não) encaminha o sinal para que o programa o receba.

ℹ️ Consultas e Informações

disassemble / disassemble <where>
Desmonta a função atual ou o escopo informado exibindo suas instruções puras em Assembly.
info args
Lista os argumentos recebidos pela função correspondente ao frame ativo no momento.
info breakpoints
Exibe o status, condições e estatísticas de todos os break- e watchpoints ativos.
info display
Lista todas as expressões configuradas para exibição automática (displays).
info locals
Imprime as variáveis locais declaradas no escopo do frame selecionado.
info sharedlibrary
Lista o mapeamento de todas as bibliotecas compartilhadas carregadas em memória.
info signals
Exibe a tabela geral com todos os sinais do sistema e suas respectivas regras de interceptação.
info threads
Lista todas as threads ativas sob o controle do processo atual.
show directories
Exibe os caminhos de busca configurados para localização de arquivos de código fonte.
show listsize
Informa o tamanho limite configurado de linhas exibidas pelo comando list.
whatis <nome_variavel>
Retorna o tipo de dado estrito associado à variável especificada.
