GUIA DE REFERÊNCIA RÁPIDA DO GDB (GDB CHEATSHEET)

===============================================================================
EXECUÇÃO (Running)
===============================================================================
# gdb <program> [core dump]
Inicia o GDB (com core dump opcional).

# gdb --args <program> <args…>
Inicia o GDB e passa argumentos.

# gdb --pid <pid>
Inicia o GDB e se anexa a um processo (attach).

set args <args...>
Define os argumentos a serem passados ao programa que será depurado.

run
Executa o programa a ser depurado.

kill
Mata o programa em execução.

===============================================================================
PONTOS DE PARADA (Breakpoints)
===============================================================================
break <where>
Define um novo ponto de parada.

delete <breakpoint#>
Remove um ponto de parada.

clear
Deleta todos os pontos de parada.

enable <breakpoint#>
Ativa um ponto de parada desativado.

disable <breakpoint#>
Desativa um ponto de parada.

===============================================================================
PONTOS DE OBSERVAÇÃO (Watchpoints)
===============================================================================
watch <where>
Define um novo ponto de observação.

delete/enable/disable <watchpoint#>
Funciona de forma idêntica aos breakpoints.

===============================================================================
<where> (Onde)
===============================================================================
function_name
Interrompe/observa a função nomeada.

line_number
Interrompe/observa o número da linha no arquivo fonte atual.

file:line_number
Interrompe/observa o número da linha no arquivo fonte nomeado.

===============================================================================
CONDIÇÕES (Conditions)
===============================================================================
break/watch <where> if <condition>
Interrompe/observa no local fornecido se a condição for atendida.
As condições podem ser quase qualquer expressão em C que avalie para verdadeiro 
ou falso.

condition <breakpoint#> <condition>
Define ou altera a condição de um break- ou watchpoint existente.

===============================================================================
EXAMINANDO A PILHA (Examining the stack)
===============================================================================
backtrace
where
Mostra a pilha de chamadas (call stack).

backtrace full
where full
Mostra a pilha de chamadas e também imprime as variáveis locais em cada frame.

frame <frame#>
Seleciona o frame da pilha sobre o qual operar.

===============================================================================
PASSO A PASSO (Stepping)
===============================================================================
step
Vai para a próxima instrução (linha de código fonte), entrando na função 
(diving into).

next
Vai para a próxima instrução (linha de código fonte), mas não entra em funções.

finish
Continua a execução até que a função atual retorne.

continue
Continua a execução normal do programa.

===============================================================================
VARIÁVEIS E MEMÓRIA (Variables and memory)
===============================================================================
print/format <what>
Imprime o conteúdo da variável, local de memória ou registrador.

display/format <what>
Semelhante ao "print", mas imprime a informação automaticamente após cada 
instrução de passo a passo.

undisplay <display#>
Remove o "display" com o número fornecido.

enable display <display#>
disable display <display#>
Ativa ou desativa o "display" com o número fornecido.

x/nfu <address>
Imprime o conteúdo da memória.
  n: Quantas unidades imprimir (padrão é 1).
  f: Caractere de formato (idêntico ao do "print").
  u: Unidade de medida.

A unidade (u) deve ser uma de:
  b: Byte
  h: Half-word (dois bytes)
  w: Word (quatro bytes)
  g: Giant word (oito bytes)

-------------------------------------------------------------------------------
Format (Formatos de exibição)
-------------------------------------------------------------------------------
a: Ponteiro (Pointer).
c: Lê como inteiro, imprime como caractere.
d: Inteiro, decimal com sinal.
f: Número de ponto flutuante.
o: Inteiro, impresso em formato octal.
s: Tenta tratar e exibir como uma string C.
t: Inteiro, impresso em formato binário (t = "two").
u: Inteiro, decimal sem sinal.
x: Inteiro, impresso em formato hexadecimal.

-------------------------------------------------------------------------------
<what> (O que exibir)
-------------------------------------------------------------------------------
expression
Quase qualquer expressão em C, incluindo chamadas de função (deve ser 
prefixada com um cast para informar ao GDB o tipo do valor de retorno).

file_name::variable_name
Conteúdo da variável definida no arquivo nomeado (variáveis estáticas).

function::variable_name
Conteúdo da variável definida na função nomeada (se estiver na pilha).

{type}address
Conteúdo no endereço informado, interpretado como sendo do tipo C "type".

$register
Conteúdo do registrador nomeado. Registradores de interesse comum são:
  $esp (ponteiro de pilha / stack pointer)
  $ebp (ponteiro de frame / frame pointer)
  $eip (ponteiro de instrução / instruction pointer)

===============================================================================
THREADS
===============================================================================
thread <thread#>
Escolhe a thread sobre a qual operar.

===============================================================================
MANIPULANDO O PROGRAMA (Manipulating the program)
===============================================================================
set var <variable_name>=<value>
Altera o conteúdo de uma variável para o valor fornecido.

return <expression>
Força a função atual a retornar imediatamente, passando o valor fornecido.

===============================================================================
CÓDIGOS FONTE (Sources)
===============================================================================
directory <directory>
Adiciona o diretório à lista de diretórios onde os arquivos fontes são buscados.

list
list <filename>:<function>
list <filename>:<line_number>
list <first>,<last>
Mostra o contexto do código fonte atual ou especificado. O nome do arquivo 
pode ser omitido. Se "last" for omitido, o contexto começando em "first" é 
impresso em vez de ser centralizado ao redor dele.

set listsize <count>
Define quantas linhas serão exibidas no comando "list".

===============================================================================
SINAIS (Signals)
===============================================================================
handle <signal> <options>
Define como manipular os sinais do sistema. As opções são:
  (no)print: (Não) imprime uma mensagem quando o sinal ocorre.
  (no)stop:  (Não) interrompe a execução do programa quando o sinal ocorre.
  (no)pass:  (Não) repassa o sinal para o programa.

===============================================================================
INFORMAÇÕES (Informations)
===============================================================================
disassemble
disassemble <where>
Desassembles (desmonta para código assembly) a função atual ou o local 
fornecido.

info args
Imprime os argumentos passados para a função no frame de pilha atual.

info breakpoints
Imprime informações sobre os break- e watchpoints configurados.

info display
Imprime informações sobre os "displays" ativos.

info locals
Imprime as variáveis locais no frame de pilha atualmente selecionado.

info sharedlibrary
Lista todas as bibliotecas compartilhadas carregadas na memória.

info signals
Lista todos os sinais e como eles estão configurados atualmente para 
serem tratados.

info threads
Lista todas as threads em execução.

show directories
Imprime todos os diretórios nos quais o GDB busca por arquivos fonte.

show listsize
Imprime a quantidade de linhas exibidas pelo comando "list".

whatis variable_name
Imprime o tipo de dado da variável nomeada.
