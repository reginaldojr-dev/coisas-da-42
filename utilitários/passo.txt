Passo a Passo Lógico — Parte Bônus da Libft (Listas Encadeadas)

Contexto obrigatório antes de começar: Todas essas funções operam sobre a 
struct t_list, que tem dois campos: void *content (o dado armazenado) 
e t_list *next (ponteiro para o próximo nó). Entender isso é o pré-requisito 
para qualquer função abaixo.


ft_lstnew
O que faz: Cria e retorna um novo nó alocado dinamicamente.
1. Alocação

Use malloc para alocar memória do tamanho de uma t_list (sizeof(t_list)).
Se a alocação falhar, retorne NULL imediatamente.

2. Inicialização dos campos

Atribua o parâmetro content recebido ao campo content do novo nó.
Atribua NULL ao campo next do novo nó. Um nó recém-criado não aponta para ninguém.

3. Retorno

Retorne o ponteiro para o nó criado.


ft_lstadd_front
O que faz: Insere um nó no início da lista.
1. Proteções iniciais

Verifique se lst ou new são NULL. Se qualquer um for, retorne sem fazer nada.

2. Encadeamento

Faça new->next apontar para o nó que atualmente é o primeiro da lista, 
ou seja, *lst. Isso conecta o novo nó ao restante da lista existente.

3. Atualização do ponteiro de cabeça

Faça *lst apontar para new. O novo nó agora é oficialmente o primeiro da lista.


ft_lstsize
O que faz: Conta e retorna o número de nós da lista.
1. Proteção inicial

Se lst for NULL, a lista está vazia. Retorne 0.

2. Contagem com loop

Inicialize um contador em 0.
Percorra a lista com um while: enquanto o nó atual não for NULL, 
avance para lst->next e incremente o contador.

3. Retorno

Retorne o valor final do contador.


ft_lstlast
O que faz: Retorna um ponteiro para o último nó da lista.
1. Proteção inicial

Se lst for NULL, a lista não existe. Retorne NULL.

2. Travessia até o fim

Percorra a lista com um while: enquanto lst->next não for NULL, 
avance para lst->next. A condição é checar ->next, não o nó atual, 
para que você pare no último nó, não depois dele.

3. Retorno

Retorne o lst atual, que agora é o último nó.


ft_lstadd_back
O que faz: Insere um nó no final da lista.
1. Proteções iniciais

Verifique se lst ou new são NULL. Se qualquer um for, retorne sem fazer nada.

2. Caso especial: lista vazia

Verifique se *lst é NULL. Se for, a lista está vazia e new se 
torna o primeiro (e único) nó. Atribua *lst = new e encerre.

3. Caso normal: lista existente

Use sua ft_lstlast para encontrar o último nó da lista.
Faça ultimo_no->next apontar para new. O novo nó agora está encadeado ao final.


ft_lstdelone
O que faz: Libera um único nó, usando uma função del para liberar o conteúdo.
1. Proteções iniciais

Verifique se lst ou del são NULL. Se qualquer um for, retorne sem fazer nada.

2. Liberação do conteúdo

Chame a função del passando lst->content como argumento. 
Ela é responsável por saber como liberar aquele tipo de dado.
Você não precisa saber o que há dentro — apenas delegar.

3. Liberação do nó

Chame free(lst) para liberar a memória da struct t_list em si.
Atenção: Esta função não deve tocar em lst->next. 
Liberar o próximo nó não é responsabilidade desta função.


ft_lstclear
O que faz: Libera todos os nós da lista a partir do ponteiro recebido, 
e define o ponteiro de cabeça como NULL.
1. Proteções iniciais

Verifique se lst ou del são NULL. Se qualquer um for, retorne sem fazer nada.

2. Loop de liberação

Percorra a lista com um while enquanto *lst não for NULL.
A cada iteração, antes de liberar o nó atual, salve o ponteiro para o 
próximo nó em uma variável temporária (proximo = (*lst)->next). Sem isso, 
você perderia o acesso ao restante da lista após liberar o nó atual.
Chame ft_lstdelone no nó atual (ou replique sua lógica: chame del no 
conteúdo e depois free no nó).
Avance *lst para o próximo nó salvo na variável temporária.

3. Finalização

Após o loop, atribua *lst = NULL para garantir que o ponteiro de cabeça 
não fique pendente (dangling pointer).


ft_lstiter
O que faz: Aplica uma função f ao content de cada nó da lista, 
sem criar uma nova lista.
1. Proteções iniciais

Verifique se lst ou f são NULL. Se qualquer um for, retorne sem fazer nada.

2. Travessia com aplicação

Percorra a lista com um while enquanto o nó atual não for NULL.
A cada iteração, chame f(lst->content) — aplicando a função sobre o 
conteúdo daquele nó.
Avance para lst->next.

3. Sem retorno

A função é void. Ela modifica os conteúdos in-place (ou produz efeitos 
colaterais), mas não retorna nada e não aloca nenhuma memória nova.


ft_lstmap
O que faz: Percorre a lista, aplica f ao content de cada nó, e cria uma 
nova lista com os resultados. Se algo falhar, usa del para limpar tudo.
1. Proteções iniciais

Verifique se lst ou f são NULL. Se qualquer um for, retorne NULL.

2. Inicialização

Declare um ponteiro para a nova lista, iniciando-o em NULL.

3. Loop de construção da nova lista

Percorra a lista original com um while enquanto o nó atual não for NULL.
A cada iteração, aplique f(lst->content) e guarde o resultado.
Crie um novo nó com ft_lstnew passando esse resultado.
Proteção contra falha (Free Guard): Se ft_lstnew retornar NULL, a alocação 
falhou. Nesse ponto, você deve chamar ft_lstclear na nova lista que estava 
sendo construída (passando del) e retornar NULL imediatamente.
Se o nó foi criado com sucesso, adicione-o ao final da nova lista com 
ft_lstadd_back.
Avance para lst->next na lista original.

4. Retorno

Após processar todos os nós, retorne o ponteiro da nova lista.
